## Purpose

This repository is created to learn quantum computing and Qiskit programming step by step.
It serves as the companion repo for my Medium article series, where each notebook demonstrates concepts with code and visualizations.

## Structure

- `part1_basic/` → Articles 1–20 (Basic Qiskit programming)
- `part2_intermediate/` → Articles 21–40 (Intermediate & advanced topics)
- `part3_shock_and_awe/` → Articles 41–90 (Deep dives and creative applications)

Each notebook is named sequentially:

- article-1.ipynb
- article-2.ipynb
- article-3.ipynb
  ......

## How to Use

1. Clone the repository:

   ```Shell
   git clone https://github.com/rahul-gupta-2004/medium_qiskit_quantum.git
   ```
2. Install Qiskit:

   ```Shell
   pip install qiskit
   ```
3. Launch Jupyter Notebook

   ```Shell
   jupyter notebook part1_basic/article-1.ipynb
   ```

4. Run the cells step by step to explore each concept and output

## Learning Focus

- Quantum circuits and single/multi‑qubit gates  
- Superposition, entanglement, and measurement randomness  
- Algorithms: Deutsch‑Jozsa, Grover, Simon’s, Quantum Fourier Transform  
- Noise models, transpiler passes, and error mitigation  
- Quantum machine learning and creative applications
